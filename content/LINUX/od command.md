### Useful options

| Option      | Meaning                             |
| ----------- | ----------------------------------- |
| `-c`        | Character format                    |
| `-x`        | Hexadecimal                         |
| `-d`        | Unsigned decimal                    |
| `-o`        | Octal                               |
| `-b`        | Octal bytes                         |
| `-A n`      | Don't show address                  |
| `-N number` | Read only specified number of bytes |
| `-j number` | Skip specified number of bytes      |
```
od [options] file
```
